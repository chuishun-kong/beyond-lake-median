# Raw data (not included)

The `data/raw/` directory does not contain any data. The GLORIA dataset used by
this project is public and must be downloaded separately:

- **GLORIA** → `data/raw/gloria/` — from PANGAEA.

See [`DATA_SOURCES.md`](DATA_SOURCES.md) for the DOI, expected file names, and
placement instructions. Most analyses in `experiments/` cannot run until these
data are downloaded.
